# Technologies Used:

React, Node, Express, Postgres, Prisma ORM, Tailwind CSS

# Steps to run the project:

- git clone `https://github.com/ishaangupta122/AlumniAssociation.git`

## Backend:

- cd `backend`
- npm install
- cp .env.example .env
- nodemon `index.js`

## Frontend:

- cd `frontend`
- npm install
- cp .env.example .env
- nodemon `index.js`
